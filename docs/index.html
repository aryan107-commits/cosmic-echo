THE METHOD / 02

From observation
to a question worth asking.

The workflow is intentionally modular. Each stage produces inspectable outputs, and each result remains open to review.

01
DATA ACCESSSCRIPTED

Find an observation

Query the NASA/IPAC Infrared Science Archive (IRSA) for SPHEREx observations, then retrieve a selected FITS product.

View archive query script ↗
⌁
02
IMAGE INSPECTIONLOCAL INPUTS

Understand the layers

Inspect the FITS image and relevant data extensions before processing. The current workflow uses image and zodiacal-light layers; audit tools can also inspect variance and flag layers when present.

View mask audit script ↗
⌗
03
MASK CONSTRUCTIONIN DEVELOPMENT

Separate sources from exclusions

Combine quality exclusions with detected-source regions. The V2 implementation keeps the source mask and combined mask as distinct products for inspection.

View background V2 script ↗
◌
04
BACKGROUND MODELIMPLEMENTED

Estimate the spatial background

Use Photutils Background2D with a median estimator and sigma clipping to construct a spatial background model and its RMS map.

Photutils background guide ↗
∿
05
DIAGNOSTIC CORRECTIONIMPLEMENTED

Inspect the corrected residual

The current V2 script subtracts the estimated background from the image-minus-zodiacal-light residual. The result is treated as a diagnostic product, not a final scientific conclusion.

Review the V2 implementation ↗
⊖
06
VALIDATIONUNDER REVIEW

Test what remains

Audit mask geometry and inspect variance-normalized residuals, tile statistics and spatial correlations. A successful run is not, by itself, evidence of scientific validity.

View spatial validation script ↗
⌖

THE STANDARD / 03

A result is not
the same as evidence.

COSMIC ECHO separates implementation, diagnostics and interpretation. The distinction is part of the method, not a footnote.

A / 01
⌘

Reproducibility

Record inputs, parameters, software versions and intermediate products so that computational steps can be repeated and inspected.

TRACE THE PROCESS
B / 02
⌖

Quantitative checks

Examine mask coverage, invalid values, local noise behaviour and spatial correlation rather than relying on appearance alone.

MEASURE WHAT REMAINS
C / 03
◇

Independent review

Challenge assumptions, compare alternatives and document limitations before promoting a computational result to a scientific claim.
