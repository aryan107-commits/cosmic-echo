# COSMIC ECHO

### Exploring the Changing Universe

COSMIC ECHO is a public-facing astronomical
exploration platform built around NASA's
SPHEREx mission data.

## Mission

Make astronomical observations easier to
explore, compare and understand over time.

## Planned Features

- Interactive sky viewer
- Multi-epoch image comparison
- Astronomical object exploration
- Change detection
- Scientific data visualization

## Technology

- Python
- React
- Astropy
- NumPy
- Plotly

## Project Status

Development environment established.
Research and implementation phase upcoming.
